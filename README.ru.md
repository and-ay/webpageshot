# WebPageShot

[English](README.md) | **Русский**

Расширение для Chromium-браузеров (Chrome, Edge, Яндекс Браузер, Opera, Brave; версия 121+)
и Firefox (140+), которое делает скриншоты страниц и сохраняет их в файл.

Языки интерфейса: английский (основной), французский, испанский, итальянский, немецкий, русский, украинский.
Язык выбирается по языку браузера; если перевода нет — английский. Переводы лежат в `_locales/<язык>/messages.json`,
в разметке строки подключаются атрибутами `data-i18n`, `data-i18n-title`, `data-i18n-aria` (см. `lib/i18n.js`).

## Режимы

| Режим | Что снимает | Клавиши |
|---|---|---|
| Видимая часть | то, что сейчас видно в окне | `Alt+S` |
| Вся страница | страницу целиком по высоте (прокручивает и склеивает кадры) | `Alt+A` |
| Область | прямоугольник, выделенный мышью; можно прокручивать колесом или тянуть к краю окна — область может быть больше экрана | `Alt+R` |
| Блок | элемент страницы под курсором; `↑`/`↓` — перейти к внешнему/внутреннему блоку, клик или `Enter` — снять, `Esc` — отмена | `Alt+B` |

Режимы доступны из кнопки на панели, по горячим клавишам и из контекстного меню страницы (пункт «WebPageShot»).

## Настройки (во всплывающем окне)

- формат PNG или JPG;
- после снимка — три галочки, можно в любом сочетании:
  - **сохранять в файл**;
  - **открывать превью** (в превью: сохранить в PNG/JPG, скопировать в буфер обмена, масштаб 1:1);
  - **копировать в буфер обмена** — снимок (в PNG) кладётся в буфер, его можно сразу вставить в мессенджер
    или редактор. Работает на страницах по https (и на localhost): браузер не даёт доступ к буферу страницам по http.

  Сохранение и копирование нельзя выключить одновременно, иначе снимок пропадёт: если снять одну из этих
  галочек при снятой другой, другая включится сама;
- **папка** — куда сохранять без вопросов. По умолчанию `Загрузки/WebPageShot/`, можно выбрать любую;
  выбор запоминается и после перезапуска браузера. После перезапуска браузер может один раз попросить
  подтвердить доступ к папке — если выбрать «разрешать всегда», больше спрашивать не будет;
- **спрашивать, куда сохранить** — после снимка открывается окошко с миниатюрой; Enter открывает системный
  диалог сразу в той папке, куда сохраняли в прошлый раз.

Почему так: файлы, которые скачивает расширение через `chrome.downloads`, браузер всегда кладёт в «Загрузки»
и не запоминает для них последнюю папку. Поэтому свою папку расширение хранит само, через File System Access API.
Системный диалог выбора файла браузер разрешает открыть только по действию пользователя —
отсюда окошко, в котором нужно нажать Enter.

## Установка

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`, в Яндексе — `browser://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.

Горячие клавиши меняются на странице `chrome://extensions/shortcuts` (шестерёнка в окне расширения открывает её).

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите «Загрузить временное дополнение…» и выберите архив `dist/webpageshot-firefox-<версия>.zip`
   (собирается командой из раздела ниже). `manifest.json` из папки проекта для Firefox не подходит — он для Chromium.

### Сборка архивов для магазинов

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт кладёт в `dist/` два архива:

- `webpageshot-chrome-<версия>.zip` — для Chrome Web Store, Edge Add-ons и Opera;
- `webpageshot-firefox-<версия>.zip` — для addons.mozilla.org.

`manifest.json` в репозитории — для Chromium: папку проекта можно загрузить в Chrome без предупреждений.
В Chrome-архиве из него убраны настройки Firefox (`browser_specific_settings`). Firefox-архив получает свой вариант:
фон через `background.scripts` вместо `service_worker`, без `minimum_chrome_version`, разрешения `offscreen`
и самого offscreen-документа. Версия берётся из манифеста.

Временное дополнение пропадает после перезапуска Firefox. Чтобы установить насовсем, его нужно подписать
на [addons.mozilla.org](https://addons.mozilla.org/developers/) (можно «не для публикации» — подпись бесплатная,
расширение в каталоге не появится) и поставить полученный `.xpi`.

Отличия в Firefox:

- выбрать свою папку нельзя (в Firefox нет File System Access API) — файлы идут в обычные загрузки
  Firefox, в подпапку `WebPageShot/`; строки «Папка» в настройках нет;
- «спрашивать, куда сохранить» открывает обычный диалог сохранения Firefox — он сам помнит последнюю папку;
- горячие клавиши меняются в `about:addons` → шестерёнка → «Управление горячими клавишами дополнений»
  (шестерёнка в окне расширения открывает эту страницу).

## Как устроено

- `background.js` — service worker (в Firefox — фоновая страница): запускает режимы, снимает кадры (`chrome.tabs.captureVisibleTab`),
  склеивает их на `OffscreenCanvas` и отдаёт файл на сохранение.
- `lib/page.js` — функции, которые выполняются в странице: замеры, прокрутка, оверлеи выбора области и блока.
- `lib/store.js` — IndexedDB: временные снимки (живут не дольше часа) и доступы к папке сохранения.
- `lib/save.js` — запись в выбранную папку, диалог «Сохранить как» с памятью папки, обычная загрузка.
- `offscreen/` — offscreen-документ, который пишет файлы в папку или делает blob-ссылку для `chrome.downloads`
  (service worker не умеет ни того, ни другого). В Firefox offscreen-документов нет и не нужно: фоновая страница
  сама делает blob-ссылку, а в буфер обмена пишет через `browser.clipboard.setImageData`.
- `save/` — окошко сохранения: «Сохранить как», подтверждение доступа к папке, выбор папки.
- `popup/`, `preview/` — всплывающее окно и страница превью.

Особенности съёмки всей страницы:

- шапки с `position: sticky` на время съёмки становятся обычными блоками и не повторяются на каждом кадре;
- элементы с `position: fixed` показываются один раз: верхние (шапки) — в начале, нижние (кнопки чата, баннеры) — в конце;
- закреплённые боковые меню на всю высоту окна на время съёмки прикрепляются к странице и растягиваются
  по всей её высоте, а их собственная прокрутка раскрывается — меню попадает в снимок целиком;
- кадры не затирают друг друга: последний кадр (прижатый к концу страницы) дорисовывает только новые строки;
- если прокручивается не окно, а внутренний контейнер (как во многих веб-приложениях), снимается он;
- Chrome позволяет делать не больше двух кадров в секунду, поэтому длинная страница снимается несколько секунд —
  прогресс виден на значке расширения;
- очень длинные страницы уменьшаются, чтобы уложиться в предел canvas (32767 px по стороне).

Ограничения: браузер не даёт расширениям снимать служебные страницы (`chrome://…`, `about:…`, магазины расширений),
а содержимое внутри `iframe` при выборе блока выбирается целиком, как один блок.

## Логотип и картинки для магазинов

Исходник логотипа — `store/graphics/src/logo.svg` (сетка 16×16); для 16, 24 (и 48) и 32 px есть варианты, выровненные по пикселям
(`logo-16.svg`, `logo-24.svg`, `logo-32.svg`). Логотип в окне расширения, превью и политике — `logo-24.svg`, вставленный в разметку. Значки `icons/icon*.png` и картинки для магазинов (`store/graphics/*.png`)
собираются из `store/graphics/src/frames.html` одной командой:

```
powershell -ExecutionPolicy Bypass -File store\graphics\src\render.ps1
```
